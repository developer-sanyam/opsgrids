# The artwork generator

The 51 SVGs in `public/img/` were generated by these scripts, not drawn by hand. They are kept
because art you cannot re-tune is art you have to redraw — change a theme's accent colour and
without this you are back to editing path data.

**The SVGs in `public/img/` are the deliverable.** These scripts are how they were made and how
they can be made again. Nothing at runtime reads this directory, and it is outside the Vite build.

## Running it

```bash
python3 build_qc.py     # QuickCart — packaged goods on a marigold shelf
python3 build_at.py     # Atelier — one large piece in a dark room
python3 build_tr.py     # the six trade themes — landscape stacks of material
```

`kit.py` holds the shared craft: a graded backdrop, one light from the upper left, a three-stop
body gradient per object, highlight and falloff through two gradient ramps rather than flat
black and white shapes, and a radial contact shadow instead of a blur filter — cheaper, and it
stays crisp at any scale. `sheet.py` and `hsheet.py` render contact sheets so a piece can be
judged at the size it is actually seen.

## Two constraints that are not style preferences

**Compose inside y 80..220 of the 400×300 frame.** `ImagePlate` uses `object-fit: cover`, so a
4:3 source keeps only that band when it lands in a 3:1 hero. Anything outside it is cropped away
at some size the piece will really be used at.

**Judge by rendering, never by markup.** Every one of these caught a failure only once it was
rendered to PNG: a crisp packet that read as an amphora, a chocolate bar that read as a coffee
jar, a bread loaf that read as a bun, a banana that read as a smile, a bolt head that rendered as
a diamond, a cement sack that read as a bean, and cup steam that was invisible against a pale
wall. None of that was visible in the source.

## What the art may not contain

No external URLs, no `<script>`, no `xlink`, no `<image>`, no `foreignObject`, no `data:` embeds.
The only URL in any file is the required `xmlns`. This is deliberate: the storefront is sold
onward, so every asset that ships with it has to be ours and has to be inert.
